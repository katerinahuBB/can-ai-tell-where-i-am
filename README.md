# can-ai-tell-where-i-am
An experiment investigating whether computer vision models can determine certain cities using everyday personal photographs, not ones found on the internet

## What I'm Testing

The main question is:

**Can AI tell where a photo was taken based on what it sees?**

I also want to see what happens when I remove some of the obvious clues. For example:

* Removing signs and text
* Cropping the photo
* Leaving out famous landmarks
* Comparing different types of scenes
* Comparing daytime and nighttime photos

## Dataset

The dataset will be made up of photos from my own travels. The original photos will not be uploaded to this repository.
